# Deep-Space-Rogue
一款背景是宇宙探索的文字肉鸽游戏，使用python的tkinter库实现GUI，单机开包即用，欢迎体验

# 运行环境
* python = 3.13.3+

# 运行方式
```python
python main.py
```

# 游戏内容
* 游戏分为建筑、职业、资源、研究、事件（未开发）五个模块，各个模块间相互影响，整个游戏从原始的社会一直进化到宇宙航行，同样游戏内会加入非常多的分支选择，来增加趣味和策略性
* 暂时还没规划好整体游戏的游玩时长
* 暂时还没有开发事件模块，当前只是简单的可以运行了，游戏内容会不定期更新
